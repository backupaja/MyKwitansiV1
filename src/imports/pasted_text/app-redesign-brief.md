Redesign the current application visually, but DO NOT change the
existing functionality, information architecture, content, pages,
navigation, data fields, actions, or user flows.

IMPORTANT:
The current design is already functionally complete.
Your task is ONLY to improve the visual design and user experience.

Keep EXACTLY the same:
- Existing pages
- Existing navigation items
- Existing features
- Existing data displayed
- Existing table columns
- Existing form fields
- Existing buttons and actions
- Existing transaction information
- Existing receipt information
- Existing nota information
- Existing print workflow
- Existing confirmation workflow
- Existing user flow

Do not add new features.
Do not remove existing features.
Do not invent new information.
Do not replace existing content with different content.

==================================================
VISUAL DIRECTION
==================================================

Make the application feel:

- Modern
- Playful
- Friendly
- Fresh
- Warm
- Approachable
- Energetic
- Professional enough for a finance/administrative application

The current interface feels too rigid, formal, empty, and visually flat.

Make it feel more alive and engaging without making it childish.

Think of a modern SaaS/productivity application with personality,
rather than a traditional administrative system.

The interface should have visual character while remaining practical
for daily use.

==================================================
LAYOUT AND SPACING
==================================================

Reduce unnecessary empty space.

Improve the visual density of the application so that the available
screen space is used more effectively.

Do not simply add more elements to fill empty space.

Instead improve:

- Content proportions
- Section grouping
- Card layouts
- Table density
- Page headers
- Action areas
- Navigation hierarchy
- Visual grouping
- Information hierarchy

Create a stronger relationship between related information.

The dashboard and data-heavy pages should feel informative and alive,
not like an empty document.

==================================================
COLOR
==================================================

Use a more expressive and contemporary color system.

Keep the existing red as an important brand/accent color, but refine
how it is used.

Do not make the entire interface red.

Use a balanced palette with:

- Primary red
- Soft red / light red backgrounds
- Neutral backgrounds
- Warm or slightly tinted surfaces
- Dark text
- Muted text
- Subtle accent colors for statuses and feedback

Use color intentionally to create hierarchy and visual interest.

Avoid an overly monochromatic interface.

==================================================
CARDS AND SURFACES
==================================================

Introduce modern cards and surface treatments where appropriate.

Use:

- Soft backgrounds
- Subtle borders
- Light shadows
- Moderate border radius
- Layered surfaces
- Clear grouping

Avoid excessive cards.

Cards should help organize information, not make every element look
like a separate box.

==================================================
SIDEBAR
==================================================

Make the sidebar more modern and visually interesting.

Keep the existing navigation items exactly the same.

Improve:

- Active navigation state
- Icons
- Spacing
- Typography
- Hover states
- Visual hierarchy

The active menu should be immediately recognizable.

The sidebar should have personality without becoming distracting.

==================================================
HEADER
==================================================

Modernize the header.

Keep the existing user information, notification, and logout action.

Improve their visual hierarchy and spacing.

Make the header feel integrated with the application rather than
looking like a separate empty horizontal area.

==================================================
DATA TABLE
==================================================

The transaction table is an important part of the application.

Keep ALL existing columns and information.

Do not remove or rename table columns.

Improve the table visually through:

- Better row spacing
- Clearer column hierarchy
- Subtle row separation
- Hover feedback
- Better typography
- Better alignment
- Improved checkbox styling
- Better search field
- Better pagination / table controls if they already exist

Make the table feel modern and easier to scan.

Do not turn the table into cards.

==================================================
BUTTONS
==================================================

Make buttons more modern and expressive.

Keep their existing actions.

Use:

- Clear hierarchy
- Comfortable padding
- Moderate rounded corners
- Strong hover feedback
- Subtle transitions
- Appropriate icons where already applicable

The primary action should stand out clearly without dominating the
entire page.

==================================================
FORMS
==================================================

Make forms feel friendly and easy to use.

Improve:

- Field grouping
- Labels
- Input styling
- Spacing
- Focus states
- Validation states
- Action button placement

Do not change the existing fields.

Do not add new fields.

==================================================
MICRO-INTERACTIONS
==================================================

Add subtle, polished interactions where appropriate:

- Button hover
- Navigation hover
- Table row hover
- Input focus
- Modal transitions
- Toast notifications
- Dropdown transitions
- Success feedback

Animations should feel smooth and lightweight.

Do NOT use excessive animations.

==================================================
PLAYFULNESS
==================================================

The application should feel playful through:

- Color accents
- Friendly visual hierarchy
- Soft shapes
- Interesting but subtle icon treatment
- Small decorative details
- Friendly empty states
- Micro-interactions
- Better visual rhythm

Do NOT use:

- Cartoon illustrations everywhere
- Childish graphics
- Excessive stickers
- Excessive emojis
- Excessive gradients
- Heavy glassmorphism
- Neon colors
- Overly decorative backgrounds

The goal is:

"playful professional"

NOT:

"corporate and boring"

and NOT:

"playful children's application".

==================================================
TYPOGRAPHY
==================================================

Use a modern, highly readable type system.

Create stronger hierarchy between:

- Page title
- Section title
- Body text
- Labels
- Table text
- Supporting text
- Numbers
- Status information

Avoid oversized headings that create unnecessary empty space.

==================================================
OVERALL FEEL
==================================================

The final interface should feel like a modern product that someone
would actually enjoy using every day.

It should be:

Modern + Playful + Professional + Practical

while preserving 100% of the existing functionality and information.

IMPORTANT FINAL RULE:

DO NOT change what the application does.

Only change HOW the application looks and feels.
